# Preliminary independent G1 rough-terrain exploration

Archived task code, model_3000, saved training settings, training log and launch/view scripts. The custom edge-return command steers the robot toward its environment origin beyond a 3 m radius, releasing inside 1 m. It does not guarantee fall prevention. Built on Isaac Lab and Unitree G1 with AI assistance; this was preliminary independent exploration rather than the later assigned tactile-navigation map mission.

Source package: Desktop/energy model. The original Isaac Lab installation is required to run this package. Historical scripts reference E:/NVIDIA/IsaacLab. No new simulation was run for this archive, and the saved package alone does not prove current playback behavior or an energy-efficiency improvement.
