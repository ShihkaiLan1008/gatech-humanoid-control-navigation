# Tactile-controller work retrospective

This source snapshot comes from the team's tactile_controller repository and includes the local reward configuration change, supplied checkpoints/reach datasets, local training outputs, the earlier weekly report in PDF/Word/slides, and independent screening in outputs/mission_review.

The original team authors own the foundation. Local setup/training/reward experiments received AI assistance. The later screening found the tuned checkpoint's mean reference foot error (33.02 cm) worse than the reference (9.62 cm), with single-seed and unmatched-training limitations. The weekly report is preserved as a historical document, not rewritten as validation of every early claim. Read the screening alongside it.

Checkpoints and data are preserved for provenance, not executable scripts. Use the original compatible WSL Python environment and follow the original README. No new training occurred while archiving.
